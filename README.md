# City-Clinic
The database of the city clinic, which contains information about all the departments in the city, patients and doctors who work there, a list of insurance policies held by patients, a list of diseases that patients have, as well as data from all medical records.

Мы команда №3. Наш состав: Лесков Архип(ПМ), Фархутдинов Марат(ЗПМ), Гордеева Виктория, Саватеев Алексей.
Наша совместная работа всегда была очень продуктивной.

Паспорт проекта:"Городская Поликлиника"
Предметная область:Записи госпитализированных пациентов отделений
Цель:Изучение всех отделений больницы, пациентов, докторов и болезней, которыми болеют пациенты отделений
Предполагаемая польза результата: Анализируя данные, можно будет найти данные, которые помогут администрации больницы лучше организовывать работу отделений или отдельных врачей
